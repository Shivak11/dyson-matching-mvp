## Architecture
Reuse Python in one Cloudflare Container behind a Worker. Keep R2 private for a bounded durable app-state checkpoint, including a SQLite backup, uploads and cost ledgers. Restore on start. Persist paid-call reservations before calls and results afterward; no auto retry after restart. Container is a singleton for this demo. Worker holds hosted secrets, session-cookie access control, and private R2 checkpoint transport. Existing API returns are preserved. Container data is never served without the gateway.
