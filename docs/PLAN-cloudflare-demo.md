# Cloudflare developer demo

17 October 2026. User authorises deployment to the existing paid personal Cloudflare account, server-side OpenRouter secrets, manufacturer seed transfer, a premium SaaS interface and a guided developer tour. Keep this a five-minute demo. No model training, prompt, threshold, catalogue-family or provider changes. Historical runs and blind-test inputs/answers remain outside the deployment.

## Outcome
An invited Multiplier developer opens the hosted app, unlocks the demo, sees an explicitly assumed dataset recipe, inspects manufacturer catalogue entries, uploads store photos in Identify mode, receives real model decisions with qualitative confidence/evidence/cost, and exports the saved results. Tour is optional and replayable. No invented accuracy percentage.

## Design
Preserve existing app API and interaction structure. Use a restrained white and cool-grey workspace, dark readable text, one teal/green action colour, an organised sidebar and a large useful photo/result area. StyleRef Clinical Signal Minimal by @styleref supplies the visual reference: https://styleref.io/share/zqgpodfr-1a61f6ab568a . Generated by StyleRef.io. Current register overrides external copy guidance. Clear datasets separate manufacturer references from store test photos; source-backed labels and held-out ground truth belong to evaluation, not inference.

## Architecture
Reuse Python in one Cloudflare Container behind a Worker. Keep R2 private for a bounded durable app-state checkpoint, including a SQLite backup, uploads and cost ledgers. Restore on start. Persist paid-call reservations before calls and results afterward; no auto retry after restart. Container is a singleton for this demo. Worker holds hosted secrets, session-cookie access control, and private R2 checkpoint transport. Existing API returns are preserved. Container data is never served without the gateway.
